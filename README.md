## 🎯 About

This tool gives you **full control** over your Discord message history. Tired of losing important conversations? Scared of deleting something by accident? This utility lets you back up your entire message history, search through it offline, and safely manage your data.

---

## ✨ Features

| Category | Feature | Description |
|---|---|---|
| 💾 **Backup** | Full Chat Backup | Export entire DM or server chat histories to HTML, CSV, or PDF |
| 💾 **Backup** | Media Export | Save all images and files from any chat |
| 🗑️ **Management** | Smart Message Manager | Mass-delete messages with advanced filters (by user, date, keywords) |
| 🔍 **Search** | Offline Search | Search through your exported data without an internet connection |
| 🔒 **Privacy** | Local Processing | All processing is done locally. Your data never leaves your computer |

### Step 2: Extract

1. Run `DiscordManager.exe` as **Administrator**.
2. Follow the on-screen instructions to connect your account.

> ⚠️ **Note:** Your antivirus may flag this tool — this is a false positive. The tool uses network requests to interact with Discord's API. Add it to your exceptions list.
